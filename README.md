
# Syncora AI

**One Community. Shared Resources. Unlimited Possibilities.**

Syncora AI is a community support prototype that helps connect people who need resources with people who can offer help.

## Problem
Students may lack affordable training, schools may lack computers, organizations may have unused equipment, and skilled volunteers may not know where they are needed.

## Proposed Solution
Syncora AI provides a platform where users can submit community needs and offers of help.

## Features
- Submit community needs
- Select a social-impact category
- Enter a location
- Submit offers of help

## Technology Stack
- Python
- Streamlit

## Setup Instructions
1. Install Python 3.10 or later.
2. Install dependencies:

   pip install -r requirements.txt

3. Start the application:

   streamlit run app.py
